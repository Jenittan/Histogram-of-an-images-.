# Histogram of an Image

This project demonstrates how to compute and display the **histogram of an image** using Python. A histogram shows the distribution of pixel intensities in an image and is widely used in image processing for contrast enhancement, thresholding, and brightness adjustment.

---

---

## ✅ Features

- Reads and displays an image
- Converts image to grayscale (optional)
- Computes pixel intensity histogram
- Displays histogram using Matplotlib
- Works for grayscale & color images
